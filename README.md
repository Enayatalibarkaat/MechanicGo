# MechanicGo

Premium roadside assistance & mechanic booking app.

### Current build
- Next.js App Router + TypeScript
- Responsive premium UI for mobile and desktop
- Service selection and mechanic discovery
- Booking confirmation interaction
- Vercel-ready frontend foundation

### Planned integrations
Firebase OTP • Google Maps • MongoDB • Razorpay/UPI • Firebase/Ably realtime • FCM • Storage • Admin dashboard

### Local setup
```bash
npm install
npm run dev
```
